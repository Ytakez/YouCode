# Профиль, знакомство и вопросы ИИ с вариантами (YouCode 1.4)

## Что сделано
1. **Знакомство после входа через Telegram.** Сначала экран «Как вас зовут?», затем YouCode здоровается
   («Привет, <имя>! Я YouCode») и спрашивает «Можно называть вас <имя>?» с вариантами **Да / Нет / Свой вариант**:
   - Да — ИИ зовёт по имени; Нет — ИИ не называет по имени; Свой вариант — вы пишете, как к вам обращаться.
2. **Профиль.** Нажмите на верхнюю панель в боковом меню (там раньше было «YouCode · AI workspace»):
   фото и имя из Telegram, оба можно поменять. Фото берётся из Telegram при первом входе; своё фото — нажать на аватарку.
3. **Карточка с вариантами, когда ИИ задаёт вопрос.** Приложение ловит запрос движка (инструмент `question`)
   и показывает окно с вариантами, «Свой вариант», кнопками «Пропустить» и «Ответить». Ответ уходит ИИ, и он продолжает работу.
   Чтобы ИИ задавал вопросы именно так, это правило добавлено в системный промпт и в каждый запрос.
   Имя пользователя тоже передаётся ИИ в каждом запросе.

## Что нужно сделать на сервере (один раз)
1. Supabase → SQL Editor → выполните **весь** `supabase/setup.sql` заново (он идемпотентный): появятся поля профиля,
   функция `update_my_profile`, корзина `avatars` и её правила.
2. Задеплойте обе функции заново (в них добавлена выгрузка аватарки из Telegram):
   ```
   supabase functions deploy telegram-auth --no-verify-jwt --project-ref gzuzyagiqgvpeqkksaml
   supabase functions deploy telegram-webhook --no-verify-jwt --project-ref gzuzyagiqgvpeqkksaml
   ```
   Секреты не меняются (`TELEGRAM_BOT_TOKEN` нужен теперь и функции `telegram-auth`: он уже задан для проекта).
3. Соберите APK как обычно.

## Важно
- Уже существующие аккаунты пройдут знакомство один раз при следующем запуске (у них `onboarded = false`).
- Фото из Telegram подтягивается при **входе**, и только если своего фото в профиле ещё нет.
  Если у человека нет фото в Telegram или оно скрыто настройками приватности, останется буква имени.
- Если ИИ всё же задал вопрос текстом, а не карточкой — это решает модель; правило ей передаётся в каждом запросе,
  но слабые бесплатные модели иногда его игнорируют.
